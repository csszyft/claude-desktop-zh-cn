# Windows 4.29 视觉与功能回归

本清单只用于本仓库的缓存方案，不提供另一套安装入口。需要安装时，先读 [Windows 4.29 指南](../../../docs/windows-overlay.md)，并取得用户同意。用户已经有正在运行的任务时，不要擅自关闭或重启 Claude。

## 验收前

- 确认使用本仓库代码，目标为已经验证的 4.29.0.0 x64。
- 确认 finish 阶段成功，EXE 的官方签名有效，两个 ASAR 与备份的官方原文件一致。
- `READY` 必须是本次缓存的标记；旧日志不能替代本次安装结果。
- 使用当前环境提供的电脑操作工具，按其文档绑定真实窗口。工具被用户停止时就停止，不改用另一种自动化手段接管窗口。

## 界面核对

观察主界面、设置、模型说明和原生菜单。检查漏译、截断、图标和布局，但不要修改账号、隐私或系统设置。聊天正文、代码和模型名称保持原文不算漏译。

截图前避开账号信息、网关地址和任务内容。截图可以证明界面语言，不能证明工作区能执行任务。

## Cowork 核对

在用户允许的测试会话中执行无副作用的简单命令，例如 `echo ok`。不要修改正在进行的业务任务，也不要为了检查功能点击“重新安装工作区”。

日志中如果出现 `signature verification failed: client executable is not signed`，先核对是否还处于 seed 阶段，或是否误用了旧式安装器。不要关闭签名校验；恢复步骤只按本仓库指南操作。

完成报告分别记录：官方文件是否恢复、界面是否中文、实际 Cowork 命令是否成功。服务进程存在或设置页正常，都不能单独算作 Cowork 验收通过。

## 未通过时

记录 Claude 版本、缓存构建标识、失败阶段和脱敏后的错误片段。先保留现场，不删除配置、缓存目录、会话目录或虚拟磁盘。需要反馈时使用 [本仓库 Issues](https://github.com/csszyft/claude-desktop-zh-cn/issues)。
