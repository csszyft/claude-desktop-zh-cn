01方案 · Approach

改译文，不关闭签名校验。

界面能打开不等于工作区能用。安装结束后，还要确认官方文件恢复、中文保留、Cowork 任务能执行。

01

本地静态缓存

只覆盖清单里的 JS 和词库，不缓存 API、模型请求、聊天记录或远程页面。

02

恢复官方文件

缓存就绪后还原 EXE 和两个 ASAR。没有修改 Cowork 服务，也没有关闭签名检查。

03

版本不匹配就回退

页面构建标识变化后使用原始资源，不把旧译文硬套到新版。它不是自动升级适配器。

原文件备份哈希校验不改全局更新策略
02安装 · Install

只按本仓库的三个阶段操作。

需要 PowerShell 5.1、Python 3.10+ 和约 3 GB 空间。先退出 Claude、等更新完成，再阅读完整指南；不要运行旧的一键安装器。

1
准备副本不修改当前安装
  1. 从 csszyft 仓库克隆代码，或下载 main 源码并解压。
  2. 确认 Claude 为 4.29.0.0 x64，原始 EXE 签名有效。
  3. 按指南运行 prepare_windows_overlay.ps1，在仓库外生成工作副本。

源码下载不是打包好的安装器。不要跳过适用范围和备份检查。

2
写入缓存seed 阶段
  1. 运行本项目的 apply_windows_overlay.ps1，使用 seed 计划。
  2. 确认结果为成功，从开始菜单打开 Claude，不要发起任务。
  3. 等本次安装的 READY 标记出现，再进行第三步。

此阶段 Cowork 仍不可用。 临时文件会使签名失效，必须继续恢复官方文件。

3
恢复并验收finish 阶段
  1. 用同一工具执行 finish 计划，还原官方 EXE 和 ASAR。
  2. 重新打开 Claude，检查主界面和菜单是否仍是中文。
  3. 在 Cowork 中执行一次简单命令，确认工作区恢复。

若缓存失败或安装中断，按指南使用 recover 计划；不要重装工作区或删除会话数据。
